# Image Recognition Using Teachable Machine

## Project Description
This project uses Teachable Machine by Google to train an image recognition model that can classify images into two classes: Dog and Cat. The trained model was exported in TensorFlow → Keras format and tested using Python in Google Colab.

## Steps

### Step 1: Create the Model
- Opened Teachable Machine by Google.
- Selected Image Project.
- Created two classes:
  - Dog
  - Cat

### Step 2: Add Training Images
- Added 2 images of dogs to the Dog class.
- Added 2 images of cats to the Cat class.

### Step 3: Train the Model
- Clicked Train Model.
- Waited until the training process was completed.
- Tested the model to evaluate its performance.

### Step 4: Export the Model
- Clicked Export Model.
- Selected TensorFlow → Keras.
- Downloaded the exported model files (`keras_model.h5` and `labels.txt`).

### Step 5: Test the Model in Google Colab
- Opened Google Colab.
- Copied the Python code generated by Teachable Machine.
- Uploaded the model files and the test image.
- Ran the Python script to classify the image.

### Step 6: Output
- The model successfully predicted the image class.
- A screenshot of the output is included in this repository.

## Repository Files
- untitled0.py – Python script used to load the model and classify images.
- keras_model.h5 – Trained TensorFlow Keras model.
- labels.txt – Class labels (Dog and Cat).
- dogg.jfif – Dog image used for testing.
- d.jpg – Second dog image.
- cat.jfif – Cat image used for testing.
- cat-s.jfif – Second cat image.
- output colab.png – Screenshot of the prediction result.
